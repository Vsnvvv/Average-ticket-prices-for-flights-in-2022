
# Analysis of Average Ticket Prices and Passenger Trends (2022)

## 📌 Project Overview
This project analyses an airline dataset from **2022** to explore **average ticket prices**, **daily passenger trends**, and **seasonal travel patterns**. The analysis uses statistical techniques and signal processing methods, including **Fourier Series approximation** and **Power Spectrum analysis**, to identify trends and periodic behaviour in passenger data.

The project provides meaningful insights into how passenger numbers vary across the year and how pricing and demand are related.

## 📊 Dataset Description
The dataset contains approximately **730 records** with the following variables:
- Day  
- Date  
- Flight Number  
- Ticket Price  
- Revenue  

The dataset contains **no missing values** and includes a mix of numerical and categorical data types.

---

## 🔍 Key Analysis Steps

### 1. Data Exploration
- Examined dataset structure and data types
- Verified data quality and completeness

### 2. Passenger Trend Analysis
- Calculated **monthly average daily passengers** using the mean
- Applied **Fourier Series approximation (8 terms)** to smooth passenger trends
- Identified seasonal patterns and peak travel periods

### 3. Frequency Analysis
- Used **Power Spectrum analysis** to detect dominant travel patterns
- Calculated the **main period** to understand long-term passenger variation

### 4. Ticket Price Analysis
- Calculated the **average ticket price for 2022**
- Linked pricing insights with passenger behaviour

---

## 📈 Key Insights
- Passenger numbers increased steadily from **January to June**
- **July** showed a sharp peak in daily passenger numbers, indicating peak travel season
- Passenger numbers declined and stabilised after July through December
- Average ticket price for 2022 was **£47.44**
- Power spectrum analysis revealed strong periodic patterns in passenger data
